# Демо на 3 минуты

Только то, что проверено (03.11.2026, режим MOCK, Chromium; браузерные сценарии: `npm run test:e2e`). Все документы
**синтетические**, компании вымышленные. Работа разделена по правилу «New work only»: что сделано **во время
хакатона**, отмечено ★; основа (сверка, загрузка PDF, дело груза) сделана до тега `pre-hackathon` и показывается
только как фон. Подробно: [docs/NEW_WORK.md](NEW_WORK.md).

## Подготовка

```bash
npm install
npm start          # режим MOCK: разбор по шаблону, это не ИИ, так и говорим
```

Откройте http://localhost:3000, нажмите «Удалить все мои данные», затем «Новое дело». Файлы: папка `demo/`.

## Что не показываем как готовое

- **Бесплатная модель (Gemini/Groq) и Meta с настоящими ключами не запускались.** После проверки дописать:
  `[0:__–0:__ — режим LLM_PROVIDER=___, модель ___: баннер «демо-режим», чтение фото 05-packing-list-photo.png: ___ (дата)]`
- Бенчмарк на модели (`npm run compare`) не запускался: нет ключа. Строка для результата:
  `[наша цепочка ___/___ против одного запроса ___/___, модель ___, дата ___]`
- Юридические документы: черновики, не проверены юристом; казахские тексты требуют вычитки носителем.
- Правила «Инспектора» демонстрационные (`needs_review`): в кадре видна пометка «демо».
- Деплой не делался.
