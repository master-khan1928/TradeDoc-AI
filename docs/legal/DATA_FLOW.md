# Поток данных

Что уходит в модель, куда, что хранится и сколько. Состояние на 03.11.2026; код: `lib/extract/index.js`,
`lib/upload.js`, `lib/pii.js`, `lib/extract/limits.js`, `public/case-store.js`.

```
Браузер пользователя                 Сервер TradeDoc AI (только память)          Внешний провайдер ИИ
─────────────────────                ──────────────────────────────────          ─────────────────────
файл (PDF/фото/TXT) ── POST /api/read ──> формат по сигнатуре, лимит 1,5 МБ
                                          PDF: текст извлекает код (unpdf) ───── в модель НЕ уходит
                                          фото: ─────────────────────────────────> изображение как есть
                                                                             <──── расшифровка + поля
                     <── текст / поля ──  проверка цитат по расшифровке
тексты документов ── POST /api/check ──> маскирование персональных данных
                                          (бесплатный тариф: при признаках
                                           реальных данных отправка запрещена) ──> замаскированный текст
                                                                             <──── поля JSON по схеме
                                          проверка цитат, сверка КОДОМ
                     <── замечания ────
localStorage: «дело груза», согласие, язык (пока пользователь не удалит)
```

## Что маскируется перед отправкой текста в модель

| Что | Как распознаётся | Чем заменяется | Нужно ли для сверки |
|---|---|---|---|
| ИИН/БИН | 12 цифр с верной контрольной цифрой (заглушки из одинаковых цифр пропускаются) | `[скрыто: ИИН/БИН]` | нет |
| e-mail | адрес вида `имя@домен` (кроме example.com, .test, .invalid) | `[скрыто: e-mail]` | нет |
| Телефон | `+` и 10-15 цифр (заглушки с шестью нулями подряд пропускаются) | `[скрыто: телефон]` | нет |
| IBAN (KZ) | `KZ` + 18 знаков с проверкой mod 97 | `[скрыто: IBAN]` | нет |
| Номер паспорта / удостоверения | после слов «паспорт», «passport», «удостоверение личности» | `[скрыто: паспорт]` | нет |
| ФИО | значение в строках «Водитель:», «Driver:», «ФИО:», «Представитель:» | `[скрыто: ФИО]` | нет |

**Не маскируется:** названия компаний (нужны для сверки сторон), веса, количества, суммы, даты, коды ТН ВЭД,
номера инвойсов. **Адреса физлиц отдельно не распознаются** (их трудно отличить от адресов компаний): в документах
компаний обычно адреса юрлиц. Это ограничение: [проверить юристом], нужно ли больше.

**Изображения не маскируются** (своего распознавания нет): фото уходит провайдеру как есть. Поэтому в режиме
бесплатной модели разрешены только синтетические документы, а для реальных фото нужен режим с договорными
условиями провайдера (например, Meta после получения ключа) [проверить юристом].

## Где что хранится и сколько

| Где | Что | Срок |
|---|---|---|
| Сервер | файл и текст | только на время запроса (оперативная память); диск, база, журналы: нет |
| Сервер, кэш | результат чтения синтетики бесплатной моделью | до 30 минут, до 200 записей, только бесплатные провайдеры; `LLM_CACHE=off` выключает |
| Журнал сервера | строка запуска, факт включения запасного режима JSON | без текстов, ключей и персональных данных |
| Браузер (localStorage `td:*`) | дела, версии документов, история проверок, согласие, язык | до кнопки «Удалить все мои данные»; лимиты: 20 дел, 10 версий, 50 проверок |
| Провайдер ИИ | то, что отправлено | по правилам провайдера; бесплатные тарифы могут использовать данные для улучшения продуктов |
