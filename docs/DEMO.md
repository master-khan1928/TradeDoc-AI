# Демо на 90 секунд

В сценарии только то, что проверено на этих файлах (26.10.2026, режим MOCK, браузер). Все документы
**синтетические**, компании и адреса вымышленные. Режим MOCK читает текст по шаблону «Метка: значение»
и **не является ИИ**: так и говорим, если на экране значок «демо-чтение (MOCK)».

## Подготовка (до записи)

```bash
npm install
npm run demo-files
npm start
```

1. `npm run demo-files` кладёт в папку `demo/` пять файлов:

   | Файл | Что это |
   |---|---|
   | `01-invoice.pdf` | инвойс, PDF с текстовым слоем, кириллица и латиница |
   | `02-packing-list.pdf` | упаковочный лист; **заложена ошибка**: в строке 1 количество 240 вместо 220 (как в инвойсе) |
   | `03-cmr.pdf` | CMR; **заложена ошибка**: вес брутто 54 200 kg, а в инвойсе и упаковочном листе 54 000 kg |
   | `04-cmr-corrected.pdf` | тот же CMR после исправления перевозчиком (вес брутто 54 000 kg) |
   | `05-packing-list-photo.png` | «фото» упаковочного листа (растровый шрифт, лёгкий шум) |

2. Откройте http://localhost:3000. Если в браузере остались прошлые дела, нажмите «Удалить всё».
3. Нажмите «Новое дело», впишите рейс, например «000 AAA 02 · Алматы → Ташкент», и дату выезда.
   Поля документов после «Нового дела» пустые.
4. Откройте папку `demo/` рядом с окном браузера, чтобы файлы можно было перетащить.

## Что в этом демо НЕ показываем как готовое

- **Чтение фото моделью (режим META) с настоящим ключом не проверено.** В MOCK фото честно не читается.
  После проверки с ключом дописать сюда:
  `[0:__–0:__ — загрузка 05-packing-list-photo.png в режиме META: ___ (результат проверки, дата)]`
- Чтение PDF моделью в режиме META с настоящим ключом тоже не проверено. В демо PDF читает код.
- Письмо одно на все замечания: оно не делится на письмо перевозчику и письмо складу.
- Вопросы «Инспектора» построены на **демонстрационных** правилах (`needs_review`, без источников).
  Если они в кадре, видна пометка «демо»; говорить о них как о проверенных правилах нельзя.
- Сцена с границей постановочная. Цифры о задержках на границе мы не называем: своих данных у нас нет.

## Если что-то пошло не так

- Тип файла не определился: перетащите его прямо на нужную колонку (тип задаётся колонкой).
- После «Удалить всё» поля пустые: это ожидаемо, перетащите файлы заново.
- Файлы можно пересоздать: `npm run demo-files` (каждый раз получаются одни и те же байты).
