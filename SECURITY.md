# Безопасность

## Как сообщить об уязвимости

Пожалуйста, не публикуйте уязвимость в открытых issues. Напишите владельцу репозитория через приватное сообщение
GitHub (Security → Report a vulnerability, если включено) или по контакту: [указать контакт]. Опишите, что и как
воспроизвести, и какие данные затронуты. Не прикладывайте реальные документы и персональные данные: только
синтетические примеры. Мы ответим и сообщим, когда исправление выйдет.

## Что входит в защиту (кратко)

- Документы не пишутся на диск и в базу данных; журналы без текстов, ключей и персональных данных. Документ живёт
  в памяти процесса на время запроса. Исключение: кэш результатов чтения бесплатной моделью (только синтетика,
  в памяти, до 30 минут, просроченное удаляется по таймеру; `LLM_CACHE=off` выключает). В кэш попадает только
  результат, прошедший проверку длины и «только синтетика».
- Ключи провайдеров ИИ только в переменных окружения; проверка секретов (`npm run secrets`) в pre-commit и CI.
  Это эвристический сканер по шаблонам, а не гарантия.
- Строгая CSP без `unsafe-inline`, `X-Content-Type-Options`, `Referrer-Policy`, `Permissions-Policy`, `X-Frame-Options`,
  HSTS на HTTPS; CORS не включён.
- Загрузка: тип по сигнатуре файла, лимит 1,5 МБ, PDF не больше 20 страниц. PDF с JavaScript (документа, страниц,
  аннотаций — проверяется через pdf.js, в том числе в сжатых объектах), вложениями и формами отклоняется; задача
  pdf.js освобождается после каждого чтения. Файлы не пишутся на диск.
- Текст документа для модели только данные: метки `<document>`, запрет выполнять инструкции из документа. Ответ модели
  проверяется локально по форме схемы (неверная форма — `bad_response`), каждое значение должно стоять в своей
  цитате, а цитата — на указанной странице; сверку делает код. Вывод на сайте только через `textContent`.
- «Только синтетика» для бесплатных тарифов проверяется перед каждым провайдером, которому уходит текст, включая
  резервного. У фото признаки реальных данных можно проверить только по расшифровке, то есть уже после отправки.
- Лимит запросов по IP, таймауты на внешние вызовы и соединения, общий бюджет не больше 3 запросов к модели
  на документ, отмена обращений к модели при закрытии клиента, ошибки без стека.
- «Удалить все мои данные» стирает ключи `td:*` в браузере и убирает со страницы результат, письмо и печатный отчёт.

## Чего защита не делает

- Аутентификации и учётных записей нет: сервис рассчитан на демонстрацию с синтетическими документами.
- Проверка Origin сравнивает только хост (схема не сравнивается); запросы без Origin (не из браузера) разрешены.
  Защита от CSRF при публичном развёртывании зависит от настроек хостинга.
- С `TRUST_PROXY=1` IP для лимита берётся из первого значения `X-Forwarded-For`: прокси хостинга должен перезаписывать
  этот заголовок, а прямой доступ к процессу должен быть закрыт.
- Разбор PDF идёт в том же процессе, что и HTTP-сервер, без отдельной изоляции по ресурсам.
- Поиск персональных данных эвристический: он ловит типичные форматы, но не всё.

Подробно: `docs/THREAT_MODEL.md`, известные ограничения: `docs/KNOWN_LIMITATIONS.md`.
